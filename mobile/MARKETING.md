## Full Description (dApp Store / Hackathon Submission)

**Batak Tournament** brings the classic Turkish trick-taking card game to the Solana Mobile ecosystem. Challenge friends or AI opponents in two authentic game modes, compete in stake-based tournaments, and earn compressed NFT trophies stored permanently on Solana.

### Game Modes
- **Koz Maça** — Spades are always trump. Bid your trick count and outplay your rivals.
- **İhaleli Batak** — Bid your suit and amount in a dynamic auction. Strategy meets psychology.

### Key Features
- **Real-time multiplayer** — 4-player rooms with WebSocket-powered instant sync
- **Private rooms** — Create a 6-character code, invite friends, fill empty slots with AI bots
- **Bot opponents** — Three difficulty levels (Easy / Normal / Hard) with adaptive strategy
- **cNFT Rewards** — Win tournaments and receive Solana compressed NFT trophies to your Seeker wallet
- **Seeker-native** — Full Mobile Wallet Adapter (MWA) integration; authorize once, play anywhere
- **SKR Stakes** — Create stake rooms with SKR tokens for skin-in-the-game competition
- **Multilingual** — Turkish, English, and 8 more languages supported
- **Trophy Gallery** — View your earned NFTs in the Settings screen
- **Leaderboard** — Global rankings by wins, tricks taken, and tournament history

### Why Solana Mobile?
Batak Tournament was built from the ground up for Seeker. The MWA integration makes wallet auth seamless — no browser pop-ups, no copy-paste addresses. Compressed NFTs keep reward minting costs near-zero so every tournament winner gets a real on-chain trophy.

### Technical Stack
- React Native + Expo (Android)
- Node.js + Socket.IO game server
- Solana Devnet + Metaplex Bubblegum (cNFTs)
- SQLite for game history and leaderboards
- JWT + Solana wallet dual authentication
