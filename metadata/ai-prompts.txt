# Upload to Arweave/Irys
Use free tier for MVP:
- Irys: `https://www.irys.xyz`
- Arweave: `https://www.arweave.org`

# Metadata Upload
```bash
# Install Irys CLI
npm install -g @irys/upload

# Upload metadata
irys upload-metadata metadata/nft-metadata.json

# Upload image
irys upload metadata/images/batak-champion.png
```
